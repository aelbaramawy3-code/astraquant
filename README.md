# AstraQuant

## AI Investment Intelligence Platform

AstraQuant is a financial technology platform designed to provide intelligent investment analysis across Egyptian, Qatari, and US stock markets.

## Vision

To build a smart investment platform that helps investors analyze markets, track portfolios, and make data-driven decisions using analytics and artificial intelligence.

## Supported Markets

- Egyptian Exchange (EGX)
- Qatar Stock Exchange (QSE)
- US Markets (NYSE / NASDAQ)

## Core Features

- Market Data Analysis
- Stock Screening
- Portfolio Management
- Technical Analysis
- Financial Analysis
- AI Investment Assistant
- Smart Recommendations

## Technology Stack

### Backend

- FastAPI

### Frontend
- React
- TypeScript
